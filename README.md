## 📌 Repository Overview
A collection of **interactive Power BI dashboards** covering various domains
including Ecommerce, HR Analytics, Entertainment, Music & Business.

---

## 📂 Dashboards

| Dashboard | Description |
|-----------|-------------|
| 🛒 Ecommerce Sales Dashboard | Sales, Profit, Customer & Regional Analysis |
| 👥 HR Analytics Dashboard | Employee Attrition & HR Metrics |
| 🎬 IMDB Dashboard | Movies & Ratings Analysis |
| 🎵 Spotify Dashboard | Music Trends & Artist Analysis |
| 🦄 Unicorn Companies Analysis | Global Unicorn Startups Insights |

---

## 🛠️ Tools & Technologies
- **Visualization:** Power BI Desktop
- **Features:** Slicers, Maps, Bar/Line/Donut Charts, Tables, DAX
